# 👋 Привет, я niperc

Я студент-разработчик, который движется в сторону **Backend / Data Engineering**.

Мне нравится не просто писать отдельные программы, а разбираться, **как целиком устроена система**: от API и базы данных до очередей, фоновых задач, инфраструктуры и процессов вокруг продукта.

Сейчас мой основной фокус — **backend, data engineering, системное мышление и developer tooling**.

> **Понимать систему → спроектировать → автоматизировать → измерять → улучшать.**

## 🚀 Что я строю

### 🛠️ [StackPilot](https://github.com/cheburek4535/StackPilot)

**StackPilot** — кроссплатформенный desktop-инструмент для разработчиков, созданный с помощью **Tauri, Rust и SvelteKit**.

Он автоматизирует рутинную часть работы с проектом:

- анализ проекта и окружения;
- создание структуры проекта;
- установку необходимых инструментов;
- настройку Docker-окружения;
- запуск компонентов проекта;
- управление workspace и процессами.

Идея проекта:

> **меньше времени на подготовку окружения — больше времени на разработку самого продукта.**

### 💼 Коммерческая разработка — Career Hub

Разрабатывал карьерный информационный сервис для образовательной организации.

Система собирает вакансии, стажировки, мероприятия и другие полезные материалы, обрабатывает их и автоматически публикует подготовленный контент.

**Стек:** Python · PostgreSQL · Docker · APIs · фоновые задачи
